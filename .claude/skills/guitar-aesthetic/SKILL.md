# Guitar Scale Visualizer (Code Chords / Guitar Story)

## What it is
A practice app that watches your fretboard through a webcam, lights up where the notes of a scale are, and listens to check you played them.

- Category: **Project**. NUS Orbital 2025, Level of Achievement: Artemis (highest). May – Aug 2025. Software Engineer & Co-Lead.
- Built: real-time YOLOv8 fretboard detection and calibration, 90% note-overlay accuracy at 30 FPS; Web Audio API pitch detection for play-along timing and scoring; tuner, YouTube speed adjuster, custom tab creator, calibration system.
- Stack: React, Vite, YOLOv8, Firebase, InferenceJS.
- Repo: https://github.com/Jyang1206/Code-Chords — Live: https://guitar-story.vercel.app/

## Assets
- Shader: `components/worlds/shaders/guitar.ts` (rosewood fretboard; with zero params it cycles six keys/scales every 7 s and plays through the notes).

## Look: stage and rosewood
- Rosewood `#2a130a`–`#5a2c16`, nickel frets, bone/cream inlays `#efe3cf`, amber spotlight `#ffb347`, warm red root notes `#e2553a`.
- Type: a characterful display (italic or rounded) for headings, friendly body; note names in a clean mono.
- Motifs: fretboard diagrams with lit dots, scale shapes, waveforms/pitch lines, stage bokeh.
- Mood: playful, musical, warm; still precise about the tech.
